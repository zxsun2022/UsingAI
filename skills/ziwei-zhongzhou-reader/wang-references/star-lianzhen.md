# 廉贞星系

> 来源：《王亭之谈紫微斗数》续星曜杂谈·廉贞篇 + 十八飞星·廉贞血疾论 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 廉贞一星最难判别

廉贞属阴火，北斗星，化为囚，在命盘是次桃花。古人有"触之不可解其祸，逢之不可测其祥"的说法——此曜守命吉凶祸福无定，须以整系星曜配合为准。

依中州派看法，廉贞最多变，虽有"次桃花"说法却未必代表守命的人有桃花或带淫荡性格。基本性质可以肯定——其人必带点轻佻，但内心主观性强，不易与人相处。有幽默感，在交际场合轻松博得一笑。但亦有"硬颈"的性质，公事上一板一眼。

## 2. 廉贞与"杀破狼"的星系组合

跟廉贞有重要关系的星曜为天相、七杀、破军、天府、贪狼：

- **子午宫，廉贞与天相同度**，对宫破军。重点在于廉贞是否见禄。甲午生人廉贞化禄；丁年己年禄存在午；癸年禄存在子——有利。丙年廉贞化忌成下格。多数不利父母。
- **丑未宫，廉贞与七杀同度**。可构成"雄宿乾元格"及"廉贞清白格"（见吉无煞），亦可极凶（见煞刑忌主战死沙场、殉职）。吉凶变化极大。
- **寅申宫，廉贞独坐**，与贪狼相对。"次桃花"会"正桃花"，本应水性杨花，但据经验艺术色彩浓厚，对颜色配搭有独到眼光。见禄反成"清白"之格。
- **卯酉宫，廉贞与破军同度**。带危险性质。"廉破火铃同宫，狼心狗肺"，"廉破加四煞，公门胥吏"。但有"反格"——廉贞化忌时反主横发横破。
- **辰戌宫，廉贞与天府同度**。廉贞最喜与天府同居辰戌。见昌曲则风雅高尚——"廉贞遇文昌好礼乐""遇帝座则主执威权，遇昌曲则施礼乐"。
- **巳亥宫，廉贞与贪狼同度**。古人评价甚差，"主下贱之孤寒"。但如会合良好可情理兼顾带风雅色彩，在现代可从事设计。

## 3. 廉贞的重要格局

**"廉贞清白格"**：廉贞在未宫化禄，或在寅申宫见禄存。为清白上格。

**"雄宿乾元格"**：廉贞七杀在未宫有吉无煞，或廉贞在申宫有吉无煞。因廉贞阴火与七杀阴金相制为用，如矿石经火煅炼成名贵原料。

**廉贞与血疾**：廉贞具有"十八飞星"中天仗星的大部分性质，主血疾。"廉贞遇羊陀，脓血不免"——会合其它星曜易生性病。"在疾厄宫主有异疾罹己……主脓血之灾。"

## 4. 廉贞的宫位解读要点

**命宫**：廉贞守命主人心硬性狠，浮荡暴躁，容易忿争。唯与天府同度内心宽厚，贪狼同度外表圆滑。
- 廉贞喜会紫微天府，更见昌曲禄马，可由理想创成事业。不喜会武曲破军，煞忌刑凑主生意外。
- 与羊陀同度又化忌多为脓血之灾。
- 女命廉贞古人仅认为"清白格"相宜，今日应同男命推断。
- **大限流年**：不喜白虎飞躔主惹官非。不喜化忌见刑煞。

**兄弟宫**：一般感情融洽但兄弟不多。即使见辅佐吉曜亦不超过五人。
- "廉破"在兄弟宫更见火星，知交易成仇怨。

**夫妻宫**：廉贞绝非善星。见煞忌刑则男女皆主三度婚姻。仅于会照天府时不和可免克。
- 廉贞不利婚姻的根本原因：感情浓厚重视精神生活但意志力薄弱，因此易生变化。
- 女命以偏房始免刑克。现代女命见煞配年长之夫以匡救；男命宜配年少之妻。

**子女宫**：廉贞喜入子女宫，主父母子女间感情深厚，纵有误会亦易化解。亲近晚辈亦少隔膜。
- "廉贞贪狼""廉贞破军"煞刑并见时，尤其"廉破"有火星同度，每因各种缘故招致子女以怨报德。
- 廉贞在子女宫又主子女稀少。

**财帛宫**：廉贞在财帛宫的特质是在竞争是非中求财，易惹词讼或被侵吞偷盗。并非善星。
- 能成富格者仅"雄宿乾元"一格。"廉贞天相"成"财荫夹印"亦主富裕。
- 凡横发横破的趋避是"见好收篷"，得意不宜再往。

**疾厄宫**：廉贞为阴火，主阴分虚亏、心火躁急。对煞忌刑曜非常敏感且少抗御之力。
- **"廉贞贪狼"主性器官病、子宫不正、妇女暗病。**
- **"廉贞天相"为糖尿病、结石。**
- **"廉贞七杀"为肺病、咳嗽、鼻敏感。**
- **"廉贞破军"亦主结石，并主意外受伤。**
- 会见诸凶时病征往往转变为重病，如由血病转化为血癌。

**事业宫**：廉贞入庙武职显赫。但亦为商业星曜——
- 与贪狼同度可从事设计或公共关系。
- 与七杀同度可经营食品业或从事手术手艺。
- 与天府同度可从事金融证券财务。
- 与天相同度为市场计划或财务计划人才，亦可成立顾问公司。
- **征验讯号**：昌曲武曲同会时主"文事武做"或"武事文做"。
- "廉贞七杀擎羊"同度居事业宫，宜从事刑法工作，否则一生至少有一次惹刑事官非。

**田宅宫**：不喜廉贞坐守。廉贞星系每多破败祖业及自置业时多困扰纠纷。
- 但将田宅视为服务机构时不能武断。即使廉贞化忌见羊陀交并又见破军七杀（最凶结构），若服务于产科医院、外科手术室、化验所或肉食业饮食业及刑法纪律部队，反而可以敬业乐业。

**福德宫**：有两种截然不同性质——自得其乐（"廉贞天府""廉贞天相"）或虽富裕仍多忧虑（"廉贞独坐""廉贞破军"）。
- "廉贞贪狼"亦可自得其乐，见昌曲重精神享受，见羊陀重物质享受。
- "廉贞七杀"不擅长思考但思虑不休，陀罗同度或化忌时为琐事不安。
- 凡廉贞坐福德宫必主忙碌。

**迁移宫**：一般主通达吉利在异乡多人缘。但有两个凶格：
- **"廉贞破军会擎羊于迁移，死于外道"**——擎羊天刑同度，当流羊叠并之年或廉贞化忌之年出门主死于异乡。
- **"廉贞七杀同位，路上埋尸"**——见廉贞化忌冲叠武曲化忌有羊陀会照或擎羊同度为流羊流陀冲起，主交通意外。
- 凡廉贞坐迁移杀破狼同度或相会见文曲化忌，主出门受骗或失窃。

**交友宫**：虽交游广阔人缘佳或手下人众多，但知心得力者稀少，且易结交损友或受手下人拖累。
- 较差宫度："廉贞七杀"与擎羊同度、"廉贞破军"与擎羊同度、"廉贞破军"与火铃同度、"廉贞破军"或"廉贞贪狼"与文曲同度——皆易招惹小人。

**父母宫**：于父母宫为恶曜，主刑伤克害或不受荫庇。仅"廉府""廉相"组合始主和美。
- "财荫夹印"的"廉相"可受父母或上司荫庇。
- **征验讯号**：廉贞化忌会武曲化忌，主父母是年有危症或死亡，或主遭上司解雇。
