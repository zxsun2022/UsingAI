# 天机星系

> 来源：《王亭之谈紫微斗数》星曜杂谈·天机篇 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 天机守命，为人灵动

天机列为南斗第一星（闽派称南斗第三星），属阴木，化气为善星。天机的基本性质主动——不主人生变动，而关涉精神活动及办事头脑的灵动。

天机可比喻为谋臣策士，宜为辅佐之士，不宜独当一面。天机对四煞非常敏感，亦无抗御空耗刑忌等恶曜的力量，即使在大运流年受到流煞冲会，亦可引起不良反应。

天机守命宫见煞同度，不宜经商，以从事专业为宜。凡天机坐命，宜专门从事一业，藉后天力量改变多学无成的缺点。

古人对天机评价不高，仅"机梁左右昌曲会，文为清显，武为忠良"始许之。但今日社会头脑愈灵动愈易立足，不可等闲视之。

## 2. 天机坐命的六种结构

天机在十二宫中，与太阴、巨门、天梁三曜关系最密切：

- **子午二宫，天机独坐**，入庙，巨门对照。灵动力和分析力最强，工程师、医师、律师多此格局。
- **丑未二宫，天机独坐**，落陷，天梁对照。灵动力大减，只能发挥分析力。最宜见文昌文曲，则分析力加强。
- **寅申二宫，天机与太阴同度**。申宫紫微天府夹命，一生权重禄凑。"机月同梁作吏人"格局出于此——主精于刀笔、工心计。
- **卯酉二宫，天机与巨门同度**。卯酉为天机旺位，但分析力被巨门削弱，仅剩灵动力。最怕再见桃花。卯宫比酉宫佳。
- **辰戌二宫，天机与天梁同度**。天罗地网位，灵动力受影响，发挥分析力，擅长思考。"高艺随身"格，现代可视为"专门学问"。
- **巳亥二宫，天机独坐**，平宫，太阴对照。太阴吸引天机，将灵动力化耗于异性方面。古书云："天机太阴巳亥逢，好饮离宗奸狡重。"须四煞及刑忌会照始是。

## 3. "机巨"与"机梁"的重要格局

**机巨同宫最怕桃花**：天机巨门在卯酉，无桃花且见禄及辅佐吉曜，可富贵但不耐久。有煞同度则为破格，主背面是非。三两点桃花会合，必重视情欲。

**机梁守命三种变局**：
- "机梁同宫辰戌，高艺随身"——天机力量较强时。工程师、教授多此命局。
- "机梁辰戌加吉曜，富贵慈祥"——天梁力量强、逢吉曜时。
- "机梁守命加刑忌，偏宜僧道"——天机完全受制，天梁极度发挥，偏于"玄想"。现代未尝不是哲学家之命。

**机梁加会格**：相传孟子命局即迁移宫在戌"机梁"同度。有时"机梁"坐迁移宫比坐命宫格局更好。

**"机月同梁"格**：天机守命寅申，会合太阴、天同、天梁。古诀"机月同梁作吏人"，主在政府或公众事业中谋发展。见禄权科主握军警大权（须不见煞忌且辅佐诸曜会照）。

## 4. 天机的宫位解读要点

**命宫**：天机守命主人机谋多变、多才多艺，但亦主游移不定。必须详察三方四正所会星曜判断好坏倾向。
- 与天梁会合且有左辅右弼天魁天钺昌曲，福厚寿长。
- 女命天机化忌，又见权科会照，喜玩弄感情；更见煞刑诸曜，婚姻始终不幸。
- 女命天机在寅申卯酉，"虽富贵不免淫佚"——但有时代限制，今日推断不如视其夫妻宫。
- **征验讯号**：凡天机火星同在命宫的人，宜防脑部神经血管疾患。

**兄弟宫**：天机在兄弟宫，一般主兄弟稀少。
- "天机天梁"在辰戌同度或丑未相对，主兄弟有流产或小产，亦主容易分离。更有天刑同度，主易起争讼。
- "天机巨门"化忌，多纷争口舌。
- **征验讯号**："天机太阴"见禄再见天巫同度，主兄弟间争夺遗产。口诀"机月不宜见禄巫"。

**夫妻宫**：以"天机太阴"的组合较易完美，"天机天梁"最易滋生弊端，"天机巨门"必须见化禄化权始得美满。
- 天机与太阴相对比同宫为佳。见文曜再见桃花，配偶易为异性追求。
- 天机与天梁相对亦比同宫为佳。男女皆主与配偶年龄有差距。
- "天机巨门"同宫见禄比相对为佳。天机与巨门相对，主夫妻貌合神离。

**子女宫**：天机在子女宫不但主子少或迟得，亦主下属或追随自己的晚辈稀少（或时时更换，关系不常）。
- "天机天梁"同度或丑未相对，稍见煞即主易流产或小产。流年子女宫见此星系，常为人工流产的征兆，以擎羊或流羊同度为确。
- "天机太阴"同度，桃花诸曜重重但见辅弼，主"姑子归宗"。

**财帛宫**：天机临财帛宫主财来财去。
- "天机太阴"见禄存化禄，为"财赋之官"。巳亥相对则意义减少，可转化为专业人士得财。
- "天机巨门"宜"闹中取财"，竞争意味重。居子午与巨门相对时竞争尤其剧烈。
- "天机天梁"为"机谋巧计以求财"，得吉曜可成专利发明。丑未宫相对时计谋偏重商业方面。

**疾厄宫**：天机属木，主肝胆疾患。天机主思虑，亦主神经衰弱。
- "天机天梁"同度或对拱，见羊陀天刑为盲肠炎；再见火铃忌星，同会阴煞天虚劫煞等，**主胃癌或乳癌**。
- "天机太阴"同度或对拱，多主神经系统疾患。女命见化禄化权，主子宫暗疾，由内分泌失调而来。
- 天机见桃花诸曜过重，水多以生木反主过患，易成内分泌失调引发的暗病。

**事业宫**：天机临事业宫一生事业多变动。由于天机主变动，吉则兼任数职；凶则不守一业。
- "天机太阴"一般利任公职或服务大机构，主管财务会计。见禄权科始可组织财团。
- "天机天梁"多管理监察意味。见煞曜亦主落拓江湖。
- "天机巨门"宜传播广告事业，从商以主管营业部门为宜。

**迁移宫**：天机为活动多变星曜，以出门反利。
- 巨门子午坐命、会太阳化忌者，迁移宫天机独坐，仍以离开出生地为宜。
- "天机天梁"虽离乡仍恋故土，可发展成外埠本地均有商业机构，见诸吉禄马有跨国企业的可能。为较利迁移的组合。

**交友宫**：天机虽见辅佐诸曜，亦仅主交游广阔，必须左辅右弼三台八座同时照会始主得助力。
- 天机与天梁相对，天梁有吉曜同躔，主得年长友人扶持。
- "天机巨门"同宫或相对，易与友人发生误会，"始善终恶"。
- 天机太阴与桃花诸曜会照又见化忌刑煞，提防误交匪人。

**田宅宫**：天机守田宅一般主难守业，会吉亦主时时搬动。亦用来推断服务机构，主易转换工作机构或从事外务。
- "天机巨门"最易引起产业纠纷。最嫌化忌再见煞刑，主因产兴讼。
- 天机与禄存同度见忌刑，主为邻舍不和。

**福德宫**：天机守福德宫主人多思虑，易患得患失。
- 天机化忌更甚。由于忧则伤肝，天机化忌于福德宫而疾厄宫又不吉者，每每亦主患肝病。
- 见空曜华盖，多人生空幻之感。天机化科又见华盖文曲，有喜爱术数或神秘事物的倾向。
- "天机太阴"同度无煞或煞少，其人第六感觉相当强。
- "天机巨门"仅主人敏于思辩，但未必办事机敏。

**父母宫**：以"天机太阴"最利父母，"天机巨门"及"天机天梁"早年均对父母不利。
- "天机天梁"会吉曜尤其天梁化科而无太多煞曜时，主可受长辈恩惠提拔，或得严明上司。
- 天机守父母宫见桃花天马，主入赘，或供养岳家而不供养父母。

**大限流年**：天机星躔度主有变动转机，多新机会，或住宅搬迁之事。天机化忌在流年命宫或田宅宫，主住宅或办公室搬迁，但须注意风水。
