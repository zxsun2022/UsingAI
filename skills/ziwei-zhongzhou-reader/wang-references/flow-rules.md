# Flow Rules

流运分析必须以脚本输出为准，按层级叠加，不自行推算日期、四化、流曜。

## Layer Hierarchy

| 层级 | 作用 | 输出依据 |
|------|------|----------|
| 本命 | 一生结构、性格、底层资源与挑战 | `currentDetailed.palaces[].natal` |
| 大限 | 十年主题、阶段环境 | `flowStarsByRole.decadal`、tags |
| 小限 | 年内个人节奏辅助 | `flowStarsByRole.age`、tags |
| 流年 | 年度主题、外部触发 | `yearly`、`yearlyDecStar`、流年四化 tags |
| 流月 | 月度重点、短期推进 | `monthly`、流月四化 tags |
| 流日 | 当日执行、提醒、触发点 | `daily`、流日四化 tags |

## Reading Order

1. 先读本命格局，确定该领域的底色。
2. 再读大限，确认十年环境是否支持本命结构。
3. 再读流年，确认年度触发宫位、四化和岁前/将前流曜。
4. 再读流月，确认本月应事领域。
5. 最后读流日，只给执行建议和短期提醒。

## Four Transformations

- 四化顺序固定为 `[禄, 权, 科, 忌]`，只从脚本输出读取。
- 禄：资源增加、缘分、机会、流动性增强。
- 权：压力、主导、竞争、必须处理的权责。
- 科：名声、证明、贵人、小幅缓冲、文书学业。
- 忌：执念、堵点、消耗、反复关注，不等于灾难。

## Flow Evidence

每条流运判断至少包含：

- 触发层级：大限/流年/流月/流日
- 触发宫位：如流年事业宫、流月财帛宫
- 触发星曜：主星、辅星、煞曜、四化 tags
- 本命承接：该宫本命是否能承受或放大触发
- 现实建议：可以做什么、避免什么

## Prohibitions

- 不把流日问题归咎于本命人格。
- 不把流月机会夸大为长期命运。
- 不自行用口诀推四化、农历、星期几、流月天干。
- 不把单个煞曜直接断为灾祸；必须看本命、大限和多重触发。
- 不对医疗、法律、投资作确定判断，只给风险提醒和专业求助建议。
