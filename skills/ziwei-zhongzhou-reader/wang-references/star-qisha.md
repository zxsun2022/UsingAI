# 七杀星系

> 来源：《王亭之谈紫微斗数》续星曜杂谈·七杀篇 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 七杀守垣，脚踏实地

七杀属阴金，南斗星，化为权，是紫微斗数中的大将星曜。七杀是"刚猛"一路的星曜，与贪狼、破军永远在三方会照，称为"杀破狼"组合。

三者的破坏风格截然不同：破军不顾一切将旧屋夷为平地；贪狼不一定盖新房子，可能只是粉饰焕然一新；七杀则应拆就拆、应粉饰便粉饰，不作无谓的破坏，亦不只做表面工夫。

七杀守命的特点在于踏实，不会谄媚，亦不因循苟且。古书云："七杀入命身宫，见吉亦必历受艰辛。"这正是恰当的评价。

七杀守命的人肺部多先天抵抗力不足，古代因医药落后认为七杀加凶易夭折（多死于肺病喘病），现代已应不验。

## 2. 七杀守命的六种结构

跟七杀最有关的星曜除"杀破狼"外，为紫微、廉贞、武曲、天府。对宫必为天府。

- **子午二宫，七杀独坐**，对宫为"武曲天府"。"武曲天府"为财星同气，最宜见禄，可化解七杀的孤嚣。古人称"得荫庇之余气"。
- **丑未二宫，七杀与廉贞同度**。"雄宿乾元格"出于此（未宫或午宫为上格）。廉贞之柔可化解七杀之刚，吉则风流儒雅且品格刚正，凶则流为肉欲。
- **寅申二宫，七杀独坐**，对宫为"紫微天府"。"七杀朝斗"或"七杀仰斗"格。七杀受紫微制化之力不大，仍表现独立特性，独当一面。主管理力强。
- **卯酉二宫，七杀与武曲同度**。中州派以卯酉为七杀落陷（坊本无陷宫），称"杀陷震兑"。积极的星系但欠预导力，风波少且小。
- **辰戌二宫，七杀独坐（旺地）**，对宫为"廉贞天府"。与"廉贞天府"相对，多于艰苦中建立事业，魄力极大，富幻想，有韩信点兵多多益善的作风。
- **巳亥二宫，七杀与紫微同度**。"紫杀"同宫，紫微制杀为权，较独坐时少了果决，完全是"威权"的表现。多得贵人提携，能富能贵。

## 3. 七杀的重要格局

**"七杀朝斗/仰斗"格**：七杀在寅宫或申宫独坐，对宫"紫微天府"。古人说"朝斗仰斗，爵禄荣昌"，须不见煞忌刑耗方合格。必须见左辅右弼始有管理权柄。

**"雄宿乾元"格**：七杀在午宫独坐，或在未宫与廉贞同度。在子、丑二宫不入格。"廉贞七杀，反为积富之人"即此格。不入格时无化禄权科反见煞忌交集则不利。

**"杀陷震兑"**：中州派传授，七杀在卯酉落陷。古人说"七杀陷地，巧艺谋生"。见煞忌则人生多反复挫折，六亲离散。见空曜多消极。但杀居陷地宜见禄，"再逢昌曲反流离"。

七杀最畏擎羊、铃星。古人说"七杀破军，专依羊铃之虐"。亦不喜临绝地见煞同会。最喜见禄存或化禄，可解凶险之气。

## 4. 女命七杀坐福德并非娼婢

古人认为女命七杀独守福德宫"必贱无疑"，实则须视具体结构：
- 七杀子午独坐福德，命宫紫微天相：仅主不肯安于环境，不一定影响婚姻。
- 七杀寅申独坐福德，命宫廉贞天相：只须防因一时感情冲动便谈婚论嫁，依然可有幸福家庭。
- 七杀辰戌独坐福德，命宫武曲天相：最大特长是机智，善于理财用财，事业有一定发展。

## 5. 七杀的宫位解读要点

**命宫**：七杀守命主人不怒而有威，处事外表果决内实进退考虑，富计谋善策划，一生事业性重。
- 喜见禄而畏见煞。入庙见煞不过六亲孤克或一时灾难；落陷见煞刑空劫无禄化解，主重大灾病甚至横死（见禄则大倾败破财）。
- 巳亥二宫多得贵人提携；寅申多清高独当一面；辰戌魄力极大富幻想；丑未志高好胜名高于利。
- "福不全"的特性：能富贵者，则妻子有刑克、或子女无出、或疾病缠身。
- 女命今日可与男命同断，唯见煞曜婚姻终不美、多孤寂。
- **大限流年**：最忌"七杀重逢"——原局羊陀照命，流羊流陀又再冲合，主凶死。见化禄可化解变为破财。

**兄弟宫**：七杀坐兄弟须兼视命宫定兄弟数，情况较其他星曜复杂。以"廉贞七杀"在丑未会吉时最佳，主和谐且有助力。

**夫妻宫**：一般不吉，即使会禄及吉化，亦不过主得有助力之妻，必须迟婚方可偕老。
- 子午两宫受武曲"寡宿"性质影响，无禄会入则婚前波折。
- 寅申入庙，对宫"紫微天府"，婚前必经多次恋爱，初恋定不能结合。
- 辰戌庙旺，对宫"廉贞天府"，见煞有情者无缘、有缘者无情。
- 卯酉落陷，酉宫尤劣。见煞忌刑耗主生离死别或遭逢意外。

**子女宫**：主子女少。入庙旺见辅佐吉曜亦不增加子女数目，仅得一子但有女，以先女后子为佳。
- 卯酉陷宫无煞，偏房生一子或私生子。有煞则有绝嗣之虞。
- "紫微七杀"同度主有子女三人。
- 凡七杀独坐子女皆少，亦不宜招祀外子，恐反招叛逆。

**财帛宫**：入庙见禄存化禄化权化科为富格。古人口诀（中州派师传）：
- "寅申子午能横发"——入庙旺之地见禄。
- "卯酉得财亦耗磨"——落陷能横发但终归白手。
- "辰戌二宫为富局"——但见煞仍有破耗。
- "丑未积财巳亥多"——渐积成富。
- 即使是"富局"，一生亦必一次周转困难，不宜投机。

**疾厄宫**：七杀属阴金，主呼吸系统疾患。又为带威杀之星，主伤痛之厄。陷宫见煞主残疾终身。
- "廉贞七杀"同度主痨伤、肺病、咳血。
- **征验讯号**：七杀火星同度为目疾；七杀龙池同度主耳聋。
- 又主哮喘、咯血或便血，轻者为鼻窦炎。
- 会擎羊主盲阳、瘤症、便血。会陀罗手足残伤。

**事业宫**：以军警两界能显发，或办工厂实业掌握多数职工为宜。绝对不宜投机，必生破败。
- 不宜文职，落陷见煞唯投身工艺以一技傍身。因宜武不宜文，从商不如从工。
- 见空劫者宜重视本身观念，虽空中楼阁一旦成为事业即可发富。
- 见羊陀照会者，不宜军警，可从事外科手术、妇产科、牙科或需用利器行业。

**田宅宫**：不宜独坐。虽入庙见吉亦不能享受祖业。独坐见煞产业倾败。
- 以田宅推断主管机构，落陷见煞主受掣肘；更见忌星受处分。武曲化忌更见煞有停职降黜之忧。

**福德宫**：七杀入福德宫主忙碌，即使入庙见吉亦主劳心。理想多偏重个人利益，逢挫折感到命不如人，满腹牢骚。落陷见煞思想必倾向消极。
- **征验讯号**：由福德宫推断婚姻——七杀临福德宫主克夫刑伤，以迟婚继室偏房为宜。此征验为坊本所无。

**迁移宫**：命宫七杀与火铃同度为孤克不利父母，迁移宫七杀火星同度反主突发。命宫见空劫常感财禄不足，迁移宫则可从事工业兴家。
- 铃星同度武职峥嵘。命宫寅申独坐不宜背井离乡，迁移宫寅申独坐见禄马反可遇贵。

**交友宫**：一般性质不吉。入庙见吉不过主手下人众多但无助力，必须见化禄始可调和。入陷地不见煞亦主手下人生变。
- 最宜戒听谗言，亦不宜与人合作事业。见忌星煞曜须重视管理及行政制度。

**父母宫**：不宜独坐，入庙亦必少年即离父母（因七杀独立性）。
- "紫微七杀"同度为最佳结构。
- 七杀独坐对拱"紫微天府"见煞及辅佐"单星"，主有两重父母。
- 见对宫武曲化忌或廉贞化忌再见凶曜，父母于自身早岁刑伤或重大倾败。
