# 太阴星系

> 来源：《王亭之谈紫微斗数》续星曜杂谈·太阴篇 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 太阴落陷并不可怕

太阴即月亮，与太阳是一对"中天星曜"。太阴主富，太阳主贵；太阴主女，太阳主男；太阴主柔，太阳主刚；太阴属水，太阳属火。

古人认为太阴落陷（巳午未宫）会带来很大灾害，但事实上推断并没有这么简单。太阴即使落陷，亦必须见四煞空劫，而且还要有煞星同宫，再加上福德宫及身宫不好，然后才会发生不愉快的事。

以午宫的太阴为例，太阴与天同同宫皆落陷。王亭之算过一男一女都是天同太阴守午宫的命，男的是财经界经理级人物，女的是著名公关公司要员——因为凡天同太阴在午宫立命的人，虽内向，但最适宜内务工作，计划性很强，在现代社会能靠灵感变成计划。推算斗数要研究性质，不可光背口诀。

## 2. 太阴守命，兼视福德宫

太阴坐命时，最宜兼看福德宫来评价。例如太阴在戌宫守命光辉之极，但福德宫却有巨门在子宫坐守，一遇煞星便容易招惹竞争，何"一生快乐"之有？又如太阴居子（与天同同宫），福德宫一定是太阳巨门同守寅宫，如果见煞，主其人一生受精神困扰，影响天同打江山的坚忍力。

## 3. 太阴十二宫名称系统

| 巳宫 | 天休/失殿 | 主有目疾，或丈夫有名无实，有吉化反主富贵 |
| 午宫 | 天衣/寒月 | 情感丰富多幻想，不利元配 |

## 4. 太阴的星系组合

与太阴同度的星曜有三：天同、太阳、天机。其余宫度为太阴独坐。

- **天同同度或对拱**：增加太阴的内向与情绪。午宫除能成"马头带箭"格局外，每多虚浮不实的幻想。
- **天机同度或相对**：增加太阴的浮动性，落陷时多犹豫进退或不顾家室。
- **太阳同度或对拱**：必在四墓之位（辰戌丑未），其中未宫最不利（太阳近日落西山，太阴仍未光辉）。
- **太阴在卯宫**为"反背"格，见辅佐及吉化可成大富大贵之格，且年青即有成就。

太阴为夜生人的主星，喜"百官朝拱"。夜生人喜太阴，日生人不喜；女命较喜太阴，男命较不喜。

## 5. 太阴的宫位解读要点

**命宫**：太阴守命主人性情内向，聪明俊秀，善用心计。以月圆之夜生人为上格。
- 日生人落陷最不宜，"陷则克母，男且伤妻"。
- 落陷逢昌曲，增加聪明但亦增加浮荡之性。
- 女命以夜生人入庙为上格，日生人入庙次之，夜生人落陷尚可，日生人落陷最差。
- 太阴化禄权科，落陷亦能富贵。若有煞星则虽吉亦虚。

**兄弟宫**：太阴守兄弟宫，入庙主手足或平辈缘较厚，落陷则人数少或各怀心事。以"天同太阴"感情较佳，"天机太阴"见忌则多机心；落陷再见羊陀空劫，合作或拆伙容易因钱财受损。

**夫妻宫**：凡太阴坐夫妻宫，男宜配妻年少，女宜配夫年长。
- 妻宫见昌曲则妻美。
- 女命太阴独坐巳亥，夫易有外宠，必配夫长十年以上始可免。
- "太阴化禄于妻宫，主得妻财以成事业"（中州派所传）。

**财帛宫**：太阴为富星临财帛宫最为相宜。
- 太阴独坐与天同相对者多白手兴家。与天机相对者亦主自身创业。
- 与空劫大耗同宫，不宜见文曲化忌，主受骗或盗窃。
- 太阴化忌有煞同度主受引诱破财。

**疾厄宫**：太阴属阴水，故主亏损之疾。
- "天同太阴"同度或相对：水多主肾脏不健全，可表征为眼病。
- "天机太阴"同度或相对：主妇女暗病及男子神经性阳痿，亦主神经系统衰弱或过敏。

**事业宫**：太阴入庙于事业宫，煞曜少，有辅佐吉曜会拱或同度，再见禄，即能由事业进展致富。
- "机月同梁"在事业宫见禄权科，主握军警大权（须不见煞忌且辅佐诸曜会照）。
- 太阴与天机同度或相对，天机化禄太阴化忌，不宜竞争求财。

**子女宫**：太阴守子女宫庙旺主子女富有，落陷则子女软弱。落陷再见煞忌刑曜主子女有刑克，以先领养为宜。子女宫见昌曲主子女聪明；见辅弼主子女有助力能继承事业；见魁钺主子女贵显。

**迁移宫**：太阴守迁移宫由于主静主藏不宜与人竞争。入庙则多人缘；落陷则防人阴谋，见铃星陀罗尤确。"天同太阴"在子为迁移宫见吉星扶最宜出外，主在异地白手兴家。

**交友宫**：太阴独坐交友宫入庙主交益友落陷则主交损友。"太阴太阳"会昌曲主下属成群亦主多门下士，唯不宜化忌否则易招尤怨或反受拖累。

**田宅宫**：太阴在田宅宫中为吉曜。落陷时"虽吉亦有盈亏"。
- **重要征验**：大限流年太阴化忌于田宅宫见煞，兼父母宫见天刑逢白虎，主有孝服。若仅太阴化忌只主家多口舌或服务机构有是非口舌困扰。
- 女命流年见太阴化忌在田宅宫会太阳化忌见煞且见桃花昌曲，须防因自身感情困扰致家变。

**福德宫**：太阴入庙守福德宫见昌曲，主人有高雅之享受。落陷日生人不宜，主精神孤寂。太阴喜静，故即使会煞曜空劫亦不主生是非口舌之心，但少竞争能力。"太阴天机"同守福德宫、太阳独守午垣为命宫的情况下，始主人有用权术计谋的倾向。

**父母宫**：太阴守父母宫宜入庙，主与母系缘分较稳；落陷或化忌时，易见母亲灾病、缘浅或早年离家。会天梁、天寿可减轻刑克；流年见太阴化忌并会煞刑白虎时，须特别留意母亲或上司层面的压力。
