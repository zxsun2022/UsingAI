# Zhongzhou Reading Order

解读时按问题范围逐层读取，不一次性加载全部参考。

## Required For Full Natal Reading

1. `general-principles.md`
2. `palace-method.md`
3. 命宫、身宫、事业宫、财帛宫、福德宫涉及的 `star-*.md`
4. `star-systems.md` 中对应的星系结构

## Required For Flow Reading

1. `flow-rules.md`
2. 本命相关 `star-*.md`
3. 流年/流月/流日命宫与重点宫位的 `star-*.md`
4. 出现显著格局时补读 `patterns-part1.md`、`patterns-part2.md`
5. 出现辅佐、煞曜、空曜、四化冲突时补读 `auxiliary-stars.md`

## Decision Order

1. 先定层级：本命、大限、流年、流月、流日，不跨层归因。
2. 再定宫位：命宫和身宫为主体，事业/财帛/福德/夫妻/迁移等为主题宫。
3. 再定星系：同宫、对宫、三方四正组成整体，不逐星机械套断。
4. 再看环境：庙旺利陷、辅佐、煞曜、空曜、夹拱、四化。
5. 最后落地：把古代断语转译为现代职业、关系、健康管理、财务行为、迁移环境等现实语义。

## Evidence Chain Format

每条关键判断使用：

`层级 -> 宫位/角色 -> 主星星系 -> 辅煞四化/tags -> 三方四正或夹拱 -> 现实领域 -> 推断与建议`

示例：

`本命 -> 财帛宫 -> 武曲天府 -> 见禄但会空曜 -> 三方事业宫受煞 -> 收入能力强但守财焦虑 -> 建议用预算和长期资产配置约束冲动决策`
