# 贪狼星系

> 来源：《王亭之谈紫微斗数》续星曜杂谈·贪狼篇 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 贪狼与廉贞的比较

贪狼属阳木又属水，北斗星，化为桃花，为天上解灾排难的星曜。贪狼在斗数称为"正桃花"，廉贞称为"次桃花"，两星为一对重要的"对星"。

贪狼偏于阳刚——桃花摆明车马的酒色财气；廉贞偏于阴柔——桃花是偷偷摸摸的声色犬马。贪狼守命遇灾亦遇得堂堂正正。

贪狼不喜落陷，但喜遇空曜，反减少酒色财气。遇文昌文曲可成风流名士。此与廉贞最大不同——"廉贞遇文昌好礼乐"，但廉贞遇空曜却不能减少声色犬马。

贪狼对庙旺利陷的性质与其它星曜甚为不同。喜入庙（辰戌丑未），非常不喜坐旺宫（子午卯酉）。古人秘云："贪狼旺宫，终身鼠窃"——实则不过主物欲深耳，未可即视为鼠窃。

## 2. 贪狼守命六种格局

贪狼与紫微、武曲、廉贞三曜关系最密切：

- **子午二宫，贪狼独坐**，与紫微相对。子宫可成"泛水桃花"。午宫"木火通明"较佳，善计谋雄才略。
- **丑未二宫，贪狼与武曲同度**。"武贪墓中居，三十才发福"，先贫后富。主暴发，但暴发后易暴败。
- **寅申二宫，贪狼独坐**，与廉贞相对。寅宫有成"风流彩杖"的可能，见煞刑主官非。申宫吉凶交集，能创业但禁不起享受。
- **卯酉二宫，贪狼与紫微同度**。"桃花犯主"，古人认为"至淫"。须见天刑及空曜始主清白。无桃花且会吉，反主多才多艺善交际。
- **辰戌二宫，贪狼独坐**，与武曲相对。入庙，三十岁后可发。
- **巳亥二宫，贪狼与廉贞同度**。两颗桃花同度反可能变成神经过敏。巳宫比亥宫好。

## 3. 贪狼的重要格局

**"火贪"/"铃贪"格**：贪狼与火铃同度。以辰戌为上格，丑未为次格。"贪狼火铃四墓宫，豪富家资侯伯贵。"不但主暴富，会辅佐诸曜时亦主贵。须注意必须贪狼火铃同度对武曲，或"武曲贪狼"与火铃同度始为上格（武曲为财星故喜见）。

**"泛水桃花"**：贪狼独坐在子，擎羊同度；或"廉贞贪狼"于亥宫，陀罗同度。

**"风流彩杖"**：贪狼在寅宫（对宫廉贞），陀罗同度。寅宫会擎羊天刑主牢狱之灾，为变格。

**"贪居旺宫"**：古人秘云"终身鼠窃"，但实不过主执着与物欲深。后天教养差才可能发展为占有欲特殊强烈。

## 4. 贪狼的宫位解读要点

**命宫**：贪狼守命，主人圆滑活动、八面玲珑，有嗜好。有错误时人初恨之入骨终则谅之。有特殊作风能与怨仇者相处。
- 女命贪狼入命最大特点是容易有嗜好且沉溺，嗜好偏近诗酒琴棋风花雪月，又喜神秘。
- 见天刑空曜反主清白端正。
- 贪狼在午宫"木火通明"，"贪狼擎羊居午位，丙戊生人镇边疆"，亦称"马头带箭"格。
- **大限流年**：见贪狼且有吉化，或逢"火贪"、"铃贪"，主事业有良好改变（于不知不觉间发生）。见煞忌则事业于不知不觉间变坏。

**兄弟宫**：入庙主兄弟和睦互相帮助，会辅弼魁钺有兄弟三人。
- 落陷主有异母兄弟（因"廉贞贪狼"同度见煞及桃花又见辅佐"单星"）。
- 今日推断可用于同僚同学各怀异心的人际关系。

**夫妻宫**：无论男女皆不喜贪狼守夫妻宫。见煞曜不宜，见桃花恐配偶有外遇。
- 必须成"清白格"（贪狼有天刑空曜同度）婚姻始美满。
- 贪狼坐辰戌入罗网，桃花减色，仅主婚前多恋爱波折。
- 贪狼化忌守夫妻宫，无论男女皆主对配偶不满，二人学识家世年龄面貌有不相称之处。

**子女宫**：会桃花诸曜主正室无子但有女。入庙赘婿与庶子可和好，落陷则不和。
- 可用于对直接下属人际关系推断。

**财帛宫**：最喜与火铃同躔，主富厚横发或得意外之财。
- 贪狼入庙见禄存化禄终能成富。
- "武曲贪狼"必无禄存同度，只能会照禄存。若会"紫微七杀"之禄则系正业所生之财。
- "火贪""铃贪"虽主横发亦易横破，须于运限找出破败克应期及时收手。

**疾厄宫**：贪狼属阳木，主肝胆病。风亦属木，故主惊风。
- "紫微贪狼"同会主色欲引起之疾患。女子主子宫不正或宫冷无生育。
- 见羊陀火星主痔漏便血。擎羊火星同度主动手术。
- **征验讯号**：贪狼主内分泌系统疾患，有鼻头红之克应即为内分泌有疾之征，尤主肝病。

**事业宫**：主人于交际应酬中成事业。凡贪狼在事业宫皆宜外务，为公共关系人才，亦主营业推销。
- 独坐子午容易独当一面，宜自由职业带艺术享受色彩。
- 独坐寅申见煞不宜从政恐因贪污致祸。见禄存同度主自私肥己但能致富。
- 独坐辰戌会吉可从政利财赋之官。不宜见武曲在对宫化忌主经济周转困难。
- 亦宜经营娱乐享受事业，以异族为对象者最宜。

**田宅宫**：基本性质为散耗。住宅虽美观仍必有损坏时须修理。
- "火贪""铃贪"主住旧宅华厦。
- **征验讯号**：流年田宅宫贪狼落陷有火铃同度（两星皆会照者不是）更见煞耗，主火灾。
- 流年贪狼化禄主买产或装修；化忌主搬迁或大修。

**福德宫**：一般均主奔波忙碌，见煞亦主无事奔波且以奔波为乐。贪狼化忌多烦恼每事功败垂成。
- "廉贞贪狼"同度最为忙碌无功。
- 独坐辰戌见吉曜禄存化禄有火铃同度，其人多投机思考，全副精神放入投机方面并以此为乐。

**迁移宫**：会吉曜化吉星主在外快乐，且多嗜好方面应酬。
- 独坐子午见吉出门朋友众多。化忌主多应酬无收获。
- 独坐寅申忌见煞又见桃花，出外因酒色致祸。
- 独坐辰戌无吉曜即主贪花恋酒不必更见桃花。

**交友宫**：会辅佐诸吉虽主朋友下属众多，但嫌欠力。必须见天巫恩光天福始主友人下属得力——由此可见杂曜有时亦非常重要。
- 独坐寅申不见吉已有结交损友征兆。见煞忌主受下属夺权或陷害。
- 独坐辰戌无吉主下属鄙吝易生侵吞之心。"火贪"成格手下人突然增加。

**父母宫**：一般主两代感情和谐但多自利之心。无论独坐或同度入庙还须会吉始无克。
- 以"紫微贪狼"同度或贪狼与紫微相对为较佳。但见火星同度仍主早岁离家。
