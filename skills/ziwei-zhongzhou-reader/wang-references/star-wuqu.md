# 武曲星系

> 来源：《王亭之谈紫微斗数》续星曜杂谈·武曲篇 + 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 武曲财星有许多缺点

武曲是北斗第六星，属阴金，为紫微斗数中的财星。斗数正曜的主要财星共三颗——武曲、天府、太阴，但三者性质不同：武曲带实质意味，天府为财库，太阴则比较抽象（主财权或财务计划）。

武曲带孤克性质，对婚姻尤其有影响。"武曲之星为寡宿"，主对丈夫不利。但现代女子有事业，若能将刚毅性格发挥于事业中，不整天在家与丈夫相对，未尝不可发挥女性温柔，不过聚少离多在所不免。

武曲最怕"化忌"——主夫妻感情变化，或财如流水甚至负债。壬年生人武曲化忌，落于命宫、田宅宫、夫妻宫、财帛宫、事业宫皆有所不宜。但星曜配合得好仅不宜经商。

武曲亦忌见火星或铃星。"武曲火铃同宫，因财被劫"——有时非遇打劫，而是财帛上无谓损失。

## 2. 武曲与"杀破狼"关系密切

武曲配合其它星曜共六种情况：
- **子午宫，武曲与天府同垣**。天府为库藏、武曲为财星，配合得宜。最喜佐曜（左辅右弼、昌曲、魁钺）。"武曲天府同垣，见左右昌曲，主甲第恩荣。"不见佐曜反见六煞，天府"露库"，武曲孤克发挥，主短虑自私。
- **丑未宫，武曲与贪狼同垣**。"武贪墓中居，三十后发福。"非常复杂的配合。最喜见火星（火贪格），"武贪守命垣，火铃同度，主威镇边夷"。见化忌再见四煞称"技艺中人"。
- **寅申宫，武曲与天相同垣**。"逢昌曲主巧艺聪明"。同时再见辅弼则主有权有势。
- **卯酉宫，武曲与七杀同垣**。十分积极的组合但欠预导力，且带危险性。"见擎羊因财持刀"，"火星同因财被劫"。可转化为军警、屠夫、外科手术等行业。
- **辰戌宫，武曲独坐**，对宫为贪狼。有吉曜三十岁后发。最怕廉贞化忌来冲，主因赌博或女色倾家。
- **巳亥宫，武曲与破军同垣**。"难贵显，可经商"。"逢昌曲一生寒士"——武曲不喜见昌曲，气质不同。

武曲不喜见陀罗铃星，"铃昌陀武，限至投河"——不一定投河自尽，指自己的作为将自己引导至失败。

## 3. 武曲见煞的几项重要古诀

- "武曲羊陀兼火宿，丧命因财"
- "武曲羊陀主孤克"
- "武曲四煞冲破，孤贫不一，破相延年"
- "武曲火铃同宫，因财被劫"

但火星常可制擎羊之恶，既见擎羊又见火星同宫，因财被劫的可能性大减。

武曲见桃花诸曜，中年可以横发。但空曜煞曜同宫则主横发后因色倾败。

武曲不喜见禄存，这一点亦应注意。

## 4. 武曲的宫位解读要点

**命宫**：武曲守命主性情至刚至毅，处事果决。判断宜武职或文职，可视有煞无煞而定。有煞宜武职，无煞宜文职。有煞同宫宜武职文做；无煞同宫始宜军警刑法。
- 武曲最喜天府，最忌破军。"四化"及煞曜对武曲影响非常大。
- "武曲七杀"容易成带凶灾结构。古人认为"破祖淹留，发财于远郡"。
- 女命武曲主妇夺夫权，必须妇夺夫权然后可免刑克。辰戌两宫尤其如是。
- **大限流年**：最不喜经"武破"宫度，遇吉亦主是非。碰到"铃昌陀武"结构须详原局。亦不喜见"武杀"见煞曜化忌均主有意外。

**兄弟宫**：武曲临兄弟宫不和睦无帮助。
- "武曲七杀"在卯酉同度会擎羊或火星，主与兄弟同事有财帛冲突。
- 武曲化忌有羊陀夹，主自己财帛受到很大剥削。

**夫妻宫**：男命比女命为佳。虽主"妇夺夫权"但孤克成分较小。
- "武曲破军"守巳宫或"武曲天府"守午宫为夫妻宫，见吉曜齐集或七杀带财禄来会，主因妻财致富。余宫力量单薄。
- 武曲火星同度主夫妻死别生离。
- 武曲化忌见煞主丈夫无能；更见桃花则丈夫移情别恋。
- 女命武曲在夫妻宫必须迟婚始能遇良好对象。

**子女宫**：武曲坐子女宫主子女少，追随自己的后辈亦少。
- "武曲破军"或"武曲七杀"跟子女易不和。
- "武曲贪狼"子女风光恐难持久，主极迟得子，亦主婚外生子。
- 武曲在子女宫会七杀擎羊天刑又见流煞，**主子女出生时需动手术**。更化忌星子女出生即有灾病。

**财帛宫**：武曲为财帛宫主星，入庙会禄存天马化禄为大富之格。
- "武曲天府"必须会禄存化禄始为富格。
- "武曲贪狼"见火铃同度主横发，再见刑忌则横发横破。
- "武曲天相"主凭特殊技能求财，难成大富但丰足。
- "武曲七杀"亦可横发，不宜见煞否则仅主争财。
- "武曲破军"遇吉仍能发财但波澜起伏甚大。
- **征验讯号**：凡"铃昌陀武"格局主破败倾向。"武曲七杀会擎羊"、"武曲七杀会火星"皆有凶验。

**疾厄宫**：武曲属阴金，一般主呼吸系统疾病。见四煞空劫刑耗主动手术。
- **"武曲天相"主疮瘢，又如植皮手术，又主小肠痛症。**
- **"武曲破军"主牙疾，尤其为牙周病。**（重要征验讯号）
- "武破"见煞忌刑曜加流煞冲合并见阴煞天虚，为瘤肿。恶性即为癌病，多在呼吸器官，有时亦可为血癌。
- "武曲七杀"亦有同样倾向，又主手足伤残。火星同度煞刑并会主由小儿麻痹症引起之伤残。

**事业宫**：最宜武职，经商亦主鼎盛。
- "武曲魁钺居庙旺，为财赋之官。"
- "武曲贪狼，必为墨吏。"
- **"武曲天相"——武职文做或文职武做。**再见文曲更见桃花诸曜则为伶人。
- "武曲闲宫多手艺"（寅申卯酉巳亥均为闲宫），为非常准确的征验。
- 武曲与煞曜同宫不主武职；有煞会合反宜武职荣身。

**田宅宫**：武曲守田宅宫可视为产业增加之兆。
- "武曲贪狼"最利田宅，"武曲天府"次之，"武曲天相"宜买旧宅。
- 最喜贪狼带火星同会，主产业骤然增加或由产业致富（不主火灾）。
- 独嫌化忌主因置业成破耗纠纷。
- **征验讯号**：田宅宫武曲化忌会廉贞化忌，则宅中有人死亡，尤对老亲不利。
- 火星同度更见天虚大耗等曜主火灾。

**福德宫**：武曲喜临福德宫，一般主享受，但以物质享受为基础，缺乏风雅意味。
- 武曲若受制于廉贞（三方四正见廉贞化忌），反主精神挫折感。
- 武曲与破军同度或会照见煞均主奔波不安。
- "武曲贪狼"同度见桃花主风月，见文曜亦主风月（不可视为风雅）。

**父母宫**：武曲带孤克不利父母。武曲化忌羊陀夹主须二姓延生，否则先克母再克父。
- 仅"武曲天府"较少刑克，"武曲破军""武曲七杀"刑克最重。
- "武曲天相"逢"刑忌夹印"刑克亦重，唯"财荫夹印"始主父母长寿。
- 最喜逢"财荫夹印"的武曲天相，主受提携扶持。

**迁移宫**：武曲会贪狼始可许他乡得财。凡武曲坐迁移必须见吉曜齐集始主在异域贸迁顺利。
- 武曲化忌守迁移会羊陀或羊陀夹主客死他乡。会廉贞化忌主交通意外。

**交友宫**：一般交游不广，"武曲天府"为例外。
- 武曲化禄于交友宫主自身心神不安日夜奔波。
- 武曲化忌主受下属侵吞或为下属错误招致损失。
- 文曲化忌同躔主受骗。
