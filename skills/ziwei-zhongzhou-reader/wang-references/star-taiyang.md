# 太阳星系

> 来源：《王亭之谈紫微斗数》星曜杂谈·太阳篇（含日月夹命/两贵局）+ 《紫微斗数讲义》（陆斌兆著，王亭之注释）

## 1. 太阳坐命的三种特质

太阳属阳火，中天星主，化贵。古人对太阳有一偏见：庙旺则吉，落陷则凶。所谓庙旺即阳光猛烈之时辰——由卯宫开始，至午宫为如日中天，至酉宫开始日落西山，至寅宫始有出山之象。故古书有"太阳守命落陷，虽化权禄亦凶"、"太阳守命庙旺，富贵荣华"之说。中州派论太阳则客观得多，不专以昼夜宫位定吉凶。

太阳坐命有三种共通特质：

- **豪放**：一种不斤斤计较小节的量度，绝不会把别人的过失记在心头。
- **名大于利**：斗数之中太阴主富、太阳主贵，故太阳坐命者无论事业开展多大亦未必巨富，有时身价甚至不如其手下。
- **心高气傲**：即使沦居下位也常对上司不服气，除非上司确有很高声望或很强领导力。

## 2. 太阳坐命的星系组合

太阳与其它主曜同度只有三种情况；独坐时亦只对照三颗主曜。归根到底，跟太阳发生关系的主曜只有**巨门、天梁、太阴**三颗，分同宫与对宫两种：

- **子午二宫，太阳独坐**，必与天梁相对。
- **丑未二宫，太阳与太阴同度**。
- **寅申二宫，太阳与巨门同度**。
- **卯酉二宫，太阳与天梁同度**。
- **辰戌二宫，太阳独坐**，必与太阴相对。
- **巳亥二宫，太阳独坐**，必与巨门相对。

三颗关系主曜各赋予太阳不同基本性质：巨门主暗——太阳遇巨门为人仅有虚名；太阴主富——太阳遇太阴能富能贵（但亦可能仅属小圈子中的小康）；天梁主清贵——太阳遇天梁则过份守原则，成为一行一业中的知名人物，反而不为社会大众所识。具体仍须视会合诸曜而变化，绝不可见太阳落某宫就依歌诀判定。

## 3. 太阳与紫微的比较

太阳主贵，故最喜主贵的助星会合：天魁天钺、左辅右弼、文昌文曲、三台八座、恩光天贵、龙池凤阁。此六对助星若**整对**与太阳会合力量最大；若拆散（尤其三台八座、恩光天贵），则零星几颗反不如一整对有力。

太阳此性质与紫微相近（紫微亦需众吉朝拱），但有分别：

- 紫微喜天府天相朝拱，太阳则没那么喜欢。
- 紫微怕"六煞"中的贪狼破军，太阳不怕，**却独怕巨门**。
- 紫微领导力强而带威严；太阳领导力较小，但有"施而不受"的特性，较易令人亲近。
- 太阳带有紫微所无的**刑克力**：克父亲、兄长、长子，重则死亡，轻则生离或感情不佳。

故古人有"日月守命不如照合"之说——命宫不见太阳坐守而得太阳拱照，仍具"贵"的性质又能减少刑克。但今人若见太阳守命，刑克程度实不如古说之甚，贵显程度亦不如古说之甚（古人父子同居易生磨擦，今人婚后分居反能发挥太阳的感情）。用斗数算现代人，见太阳守命须格外谨慎，不应完全依古歌诀推算。

## 4. 太阳的重要格局

**"月朗天门"**：太阴守命于亥宫。古认为可封侯进爵，今则仅主有声名。须八月、十二月生人为佳（有左辅右弼会合命宫），否则格局太清，反主有名无利、寂寞孤单——所嫌者异性朋友太多，易影响事业，仅可能是"公子"而已。

**"日照雷门"**：太阳守命于卯宫，今为政客或投机家之命。宜卯时、未时、亥时生人（得文昌文曲），又生于乙年有禄存同宫，然后才有实际政见主张、造福社会；条件不足则仅多一锋头人物。两局相比，"日照雷门"优于"月朗天门"，因其人正直热心，出锋头终究对社会有利。

**"日月夹命"**：被古书视为大佳之造，但须分两种情形细辨——

- **武曲贪狼坐命丑未**（太阴、太阳分夹）。武曲财星主决断、贪狼主巧技交际，合则为商场成功人物；但武曲主迟发只能白手兴家，贪狼坏处主沉迷酒色赌博。**最怕命宫见擎羊**：命在丑则财帛宫见廉贞破军、命在未则事业宫见廉贞破军，廉破会丑未擎羊称"扭枷带锁"，主因财帛或事业致刑讼。且无论丑未，福德宫必见天相落陷，故"日月夹命"纵为佳造亦主奔波劳碌。喜魁钺辅弼昌曲成就事业，尤喜火铃（削弱好酒贪花之性）。
- **天府坐命丑未**，对宫必见廉贞七杀。丑宫喜丙年生人（禄存在巳会合），未宫喜壬年生人（禄存在亥会合）；若无禄存而会羊陀，天府既要应付廉贞七杀的消耗又心痛于保守吝啬，遂机谋百出流为权术之徒。

**歌诀矛盾的警示**："日月夹命"中天府守丑未者迁移宫必见廉贞七杀，而《太微赋》又云"七杀廉贞同位，路上埋尸"——一方说大贵、一方说客死他乡，正是硬依歌诀、不知变通则容易撞板的明证。读斗数歌诀须知其局限。

## 5. 太阳十二宫名称系统

太阳在十二宫各有传统名称，为断命的重要参考：

| 宫位 | 名称 | 要义 |
|------|------|------|
| 子宫 | 天宜 | 富于情感，主生贵子 |
| 丑宫 | 天幽 | 日月同宫，性情忽阴忽阳 |
| 寅宫 | 天桑 | 旭日东升，福厚名显 |
| 卯宫 | 天乌 | 英明俊伟，名显富裕，"日照雷门" |
| 辰宫 | 天爽 | 日出龙门，少年显达，权名远扬 |
| 巳宫 | 幽征 | 志高气傲锋芒太露，禄厚权高 |
| 午宫 | 日丽中天 | 福厚禄重，志高气壮，但日光太烈亦主目疾 |
| 未宫 | 天辉 | 日月光辉，权重豪爽 |
| 申宫 | 天暗 | 多学少成，处事多周折 |
| 酉宫 | 九空 | 做事亨通但有始无终，最忌煞星 |
| 戌宫 | 天枢 | 日藏光辉名虽不扬，遇吉曜反能成富 |
| 亥宫 | 玉玺 | 日月反背反成大局，少年立功勋 |

太阳不喜过分散射热力，巳午二宫不主富；反而戌亥两宫遇吉可成富局（光芒收敛）。此推断基于儒家"中庸"思想。

## 6. 太阳的宫位解读要点

**命宫**：太阳守命主人豪放不斤斤计较、名大于利、心高气傲。最畏化忌，不但主六亲有损，且主眼目心脏疾患。落陷见刑忌又见阴煞天虚主人猥琐。
- 寅卯为旭日东升，辰巳为入殿或日游龙门，午宫为日丽中天。
- 太阳不甚忌煞曜，见煞仅主辛劳。
- 女命入庙吉落陷凶，日生人利夜生人差。

**兄弟宫**：入庙以"光辉"为最——化权化禄最佳，化科次之。
- 太阳化忌主长子有伤，亦主父亲与兄弟不和或受兄弟拖累。
- 兄弟宫光辉适中而命宫见辅弼，主兄弟富贵有助力。

**夫妻宫**：男命胜于女命，日生人利于夜生人。
- "太阳巨门"最不宜见煞忌刑曜，常为与配偶生离死别征兆。又主亲家不和或异族通婚。
- "太阳太阴"见禄权科会吉，夫妻互借助力；见煞忌仅为婚前恋爱有挫折。
- "太阳天梁"见吉仅主夫妻年龄差距大。见凶则互相疑忌。
- 落陷化忌见刑煞，须经多次恋爱挫折且无正式婚礼始可偕老。

**子女宫**：入庙吉日生人更吉，落陷凶夜生人尤凶。太阳化忌主头胎有损且父子有严重代沟。
- **"太阳天梁"在子女宫最吉利，成"阳梁昌禄"格局，子女及晚幼必秀发。**
- "太阳太阴"有时仅主子女晚辈众多。
- 四煞并照不见化忌尚无妨（仅感情隔膜），见化忌则妨长子或提携后进反招怨报。

**财帛宫**：太阳守财帛无论庙陷有吉无吉均不易聚财。见煞刑主一生为人作嫁。
- 不喜巨门同度或对照，虽得财亦有纠纷且易成一时之富贵。
- "太阳巨门"化权禄主受异族赏识得成富。又主得异族之财，最宜进出口业。
- "太阳天梁"主争夺，凭专业知识或商标字号求财为佳。最喜科星同躔。
- "太阳太阴"见吉主先散后聚，能散财亦能聚财。
- 应检视夫妻宫及田宅宫有无守财能力，以求趋避。

**疾厄宫**：太阳属火，主"阳明"症候。又主眼目。又主"风疾"（中风）。
- **"太阳天梁"最易发生中风倾向。**煞忌刑曜重重且流煞冲合见天虚阴煞——**主乳癌（女子）或胃癌（男子）。**
- "太阳太阴"无论同宫或相对，主水火不调阴阳不和，表现为失眠怔忡，可发展为心脏脑部疾患。同度见煞又见刑伤空劫，**主破伤风**。
- "太阳巨门"防口舌疮痛（非牙病），见陀罗天刑为**半身不遂**。
- 太阳化忌——主眼目心脏疾患。许多先天性心脏病属此。午宫戌宫皆为视力不良征兆。

**事业宫**：吉则事业广大声名显赫，凶则事业空虚浮夸不实。
- 与太阴同度或拱照较踏实，可成内务人才。
- 与巨门同度或拱照宜外务，主得异族之财。
- 与天梁同度或拱照以专业为宜尤利医疗业，最不宜藉名誉来浮夸取财。
- 化忌无论何种组合都主事业受压力，只有从事以口舌竞争为基本性质的行业（法律、推销、教育、传播）始可化解。绝不宜从政。

**田宅宫**：太阳为浮动星曜，祖产有退去趋势。入庙有吉仍难免浮动变换。
- **征验讯号**：流年田宅宫见太阳刑忌煞交集又见流煞太岁白虎，主父死或宅中直系尊亲逝世。
- "太阳太阴"在未宫守田宅且见吉，产业较为稳定。
- "太阳巨门"见吉宜在外国置业。
- "太阳天梁"见擎羊天刑空劫大耗主因公产兴大讼。

**福德宫**：太阳主人喜动不喜静。见擎羊火星主无事奔忙。须见辅弼三台八座始有安静倾向。
- "太阳天梁"见吉仅宜幕后策划不可正面出头，出头易招怨成仇。见科文诸曜则为学术思考上的忙碌。见陀罗铃星天虚主食古不化主见极强。
- "太阳巨门"最为劳碌操心。
- 女命见太阳会诸吉而桃花少，主闺房多乐趣。

**迁移宫**：以"太阳巨门"最宜出门经商，化禄权科易得外地人提携。
- "太阳天梁"最利出门求学求名，最喜见昌曲。在现代又为代理外国商品的表征。
- "太阳太阴"浮动无根太甚，见吉亦主奔波。
- 凡太阳居迁移利发贵发名，不甚利于求财。

**交友宫**：太阳不宜居交友宫。即使不见煞忌亦主施恩无功，见煞忌更主恩反成仇。
- 以自身不从事政治活动为宜，政治漩涡恩反成仇后果最大。
- "太阳巨门"化权禄宜结交异族。
- "太阳天梁"比较孤立，见诸吉主可得诤友。

**父母宫**：入庙无刑克。太阳化忌主克父。流年大限太阳坐父母宫见禄马主上司调动更换；化忌则与上司意见不合；见煞主受压力。
- "太阳天梁"在父母宫上司成见极深。
- "太阳巨门"化吉以服务异族为宜。
- "太阳太阴"见忌防初时关系良好因误会转为恶劣。
