# Palace Method

十二宫不是孤立格子。每一宫都应以本宫、对宫、三方四正、身宫、四化触发共同判断。

## Core Palace Roles

| 宫位 | 主要问题 | 必须联看 |
|------|----------|----------|
| 命宫 | 性格、外在模式、整体格局 | 身宫、福德宫、迁移宫、财帛宫、事业宫 |
| 兄弟宫 | 手足、同侪、合作伙伴 | 交友宫、父母宫、财帛宫 |
| 夫妻宫 | 伴侣、长期合作、亲密关系 | 福德宫、迁移宫、事业宫、子女宫 |
| 子女宫 | 子女、下属、作品、产出 | 夫妻宫、交友宫、田宅宫 |
| 财帛宫 | 收入方式、资源流动、金钱观 | 命宫、事业宫、福德宫、田宅宫 |
| 疾厄宫 | 体质、情绪压力、风险部位 | 命宫、福德宫、父母宫 |
| 迁移宫 | 外部环境、异地发展、社会适应 | 命宫、事业宫、交友宫 |
| 交友宫 | 朋友、团队、下属、社群 | 兄弟宫、事业宫、财帛宫 |
| 事业宫 | 职业类型、组织位置、长期成就 | 命宫、财帛宫、迁移宫、福德宫 |
| 田宅宫 | 家宅、不动产、长期安全感、组织环境 | 父母宫、财帛宫、疾厄宫 |
| 福德宫 | 内在满足、精神模式、享受方式 | 命宫、夫妻宫、财帛宫、事业宫 |
| 父母宫 | 父母、长辈、上级、制度资源 | 命宫、疾厄宫、田宅宫 |

## Operating Rules

1. **命宫不独断**：命宫显示外显结构，福德宫显示内在动机，身宫显示后天用力点。
2. **财官迁联动**：事业、财帛、迁移共同决定职业机会、收入模式和外部市场。
3. **夫妻看福德**：关系质量不能只看夫妻宫；福德宫的情绪与价值观会改变关系表现。
4. **疾厄看压力源**：疾厄宫只给体质与风险方向，须结合福德宫情绪、父母宫遗传/长辈、流年触发。
5. **田宅不只房产**：田宅也可转译为家庭系统、居住环境、长期资产、服务机构或工作场域稳定性。
6. **父母可转上级制度**：成年后父母宫常反映上司、机构、制度、资质、文凭和资源背书。
7. **子女可转产出**：无子女语境下，子女宫可看作品、项目、学生、下属、创作成果。
8. **交友可转团队**：交友宫在现代常对应团队、客户社群、平台生态、下属执行力。

## Empty Palace Rule

- 空宫借对宫主星，但借星力量弱于原坐。
- 空宫仍须看辅星、杂曜、四化、流星。
- 空宫判断必须联看三方四正，不能只用对宫一句话替代。

## Modernization Rules

- 古代"科名"可转译为学历、证照、专业声誉、考试竞争、评审机制。
- 古代"官禄"可转译为组织位置、职业路径、管理权责、平台资源。
- 古代"刑克"优先转译为关系疏离、责任压力、冲突成本、资源不匹配；不得直接断死亡。
- 古代"疾病"只转译为健康管理重点或风险部位，不作诊断。
- 古代"富贵"拆成资源、声誉、权责、稳定性，不混为单一好坏。
