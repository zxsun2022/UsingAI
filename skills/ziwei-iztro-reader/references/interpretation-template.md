# 聚焦式分层解读模板

默认围绕一个有截止时间的待决事项组织回答；仅在用户明确要求完整解读时扩展为 12 宫模板。

1. 输入确认
- 出生信息（公历/农历、日期、时辰、性别、出生地）
- 出生信息确认状态（必须为已确认）
- 当前参考时区
- 参考日期（公历 + 农历）
- 数据口径声明：默认使用 `byRole`（宫位角色映射）

2. 决策对象
- 具体待决事项
- 绝对截止日期
- 本次不处理的范围

3. 相关盘面
- 只列与事项相关的宫位、三方四正、星曜、四化与 tags
- 保留必要的本命底层，不遍历无关宫位

4. 分层判断
- 按本命 → 流年 → 流月 → 流日组织 2–4 条关键判断
- 每条使用：`证据（宫位/星曜组合/四化或 tags） -> 领域落点 -> 推断结论`

5. 行动建议
- 给出不依赖命理也成立的下一步
- 写清停止条件、风险上限或复核日期

6. 限制与假设
- 缺失字段
- 未做真太阳时修正
- 结论只用于文化研究与娱乐参考

补充：
- 默认 `focused`，禁止用无关宫位堆砌篇幅。
- `chart-only` 只展示盘面数据，不输出吉凶判断或行动建议。
- `full` 才遍历 `currentDetailed.palaces[]` 输出 12 宫完整明细，并附上 `tags`。
- 每条关键结论必须配证据链：`证据（宫位/星曜组合/四化或tags） -> 领域落点 -> 推断结论`。
- 关键判断需区分层级来源（本命、流年、流月、流日），禁止跨层归因。
- 仅在开发调试时使用索引口径（`query.debug.includeIndexMapping=true`）。
- `focused` 必须一条回复完成；`full` 可在有长度限制时按编号分批继续。
