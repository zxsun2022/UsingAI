# UsingAI Knowledge Base

This directory is a file-first, Agent-operable personal knowledge base.

## Structure

- `inbox/` — incomplete or unclassified input
- `conversations/` — AI conversations and research-session archives
- `sources/` — external articles, podcasts, videos, papers, and documents
- `knowledge/` — long-lived topic synthesis and current understanding
- `projects/` — project-specific knowledge, decisions, and working documents
- `reports/` — point-in-time reviews and generated reports
- `experiments/` — proposed schemas, workflows, and structures
- `archive/` — retired or superseded material

Before writing, read the repository root `AGENTS.md` and `docs/AGENTS.md`.

The knowledge base follows three principles:

1. historical records are preserved rather than silently rewritten;
2. long-lived knowledge is separated from raw conversations and sources;
3. structural changes are reviewed through branches and pull requests.
